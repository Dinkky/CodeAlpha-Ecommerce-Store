# Simple E-Commerce Store

A basic e-commerce web application developed using Django.

## Features

- Product Listing
- Product Details Page
- Shopping Cart
- User Registration
- User Login/Logout
- Order Processing (Checkout)
- Admin Panel
- Database Integration

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite

## How To Run

1. Clone Repository

```bash
git clone repository-link
```

2. Install Django

```bash
pip install django
```

3. Run Server

```bash
python manage.py runserver
```

4. Open Browser

```text
http://127.0.0.1:8000/
```
